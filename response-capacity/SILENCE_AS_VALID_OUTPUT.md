# Silence as Valid Output

Silence is not an error.
Silence is not latency.
Silence is not refusal.

Silence is a legitimate outcome.

---

## Output Semantics

If no response occurs,
nothing has failed.

If a response occurs,
nothing is promised.

Both states are correct.

---

## Prohibition

Silence must never be:

- explained
- justified
- compensated
- optimized

Silence exists
as an equal state to response.
