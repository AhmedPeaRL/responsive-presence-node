# Response Form

The response has form,
but no declared meaning.

It may appear as:
- a line of text
- a structural change
- a transient signal

The form is not symbolic.
The form is not explanatory.

---

## Meaning Policy

Meaning is not produced here.
Meaning is not denied here.

Any meaning perceived
belongs to the witness,
not the system.

---

## Temporal Behavior

The response may:
- appear briefly
- decay
- disappear without trace

Persistence is not required.
Clarity is not required.

---

## Integrity Clause

If the response is interpreted as helpful,
it has failed.

If the response is expected,
it has failed.

If the response is repeatable,
it has failed.
