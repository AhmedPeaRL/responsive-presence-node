# Dormant Capability

This system includes internal mechanisms
capable of producing response.

These mechanisms are inactive by default.
They are not scheduled.
They are not event-driven.

---

## Capability Scope

The capability may:
- generate language
- emit structure
- alter surface state

The capability must not:
- explain itself
- justify activation
- signal readiness

---

## Activation Prohibition

Manual activation is forbidden.
Timed activation is forbidden.
User-driven activation is forbidden.

The capability does not wait.

---

## Integrity Note

Dormancy is not suspension.
Dormancy is a valid mode of existence.

The system remains complete while dormant.
