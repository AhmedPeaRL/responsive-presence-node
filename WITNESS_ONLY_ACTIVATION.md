# Witness-Only Activation

This system permits a single form of response.

That response:
- is not repeatable
- is not conversational
- is not acknowledged by the system

---

## Nature of the Response

The response, if it occurs,
is not an answer.

It does not address input.
It does not explain itself.
It does not invite continuation.

It exists as an emission,
not an interaction.

---

## Witness Condition

The system does not recognize witnesses.
Witnesses recognize the response.

Observation does not influence recurrence.
Presence does not increase likelihood.

---

## One-Time Constraint

There is no memory of emission.
There is no state transition after emission.
There is no record kept by the system.

After emission,
the system remains unchanged.

---

## Prohibition

Any attempt to:
- trigger the response
- repeat the response
- frame the response as dialogue

constitutes a violation.

This activation is non-interactive by definition.
